# 🏛️ Стратегия тестирования ILLUZGAME (документ организован ии, принципы выведены вручную)

Этот документ описывает подход к обеспечению качества проекта. 
Моя главная цель — находить баги на ранних этапах и гарантировать, что новые фичи не ломают старый функционал.

## 1. Уровни тестирования (Порядок проверок)

Мы используем приоритизированный подход: от самого критичного к деталям.

1. **Smoke-тесты (Дымовые)**
   - Проверка того, что игра "дышит". Запускается ли она? Работает ли базовый игровой цикл? 
   - Разделены по зонам: Интро, Регистрация, Игровой цикл, Смерть/Перерождение.
2. **Логика и Математика (Edge Cases)**
   - Проверка граничных значений (например, возраст 15.9 и 16 лет, сумма шкал Мрака/Света = 100%).
   - Проверка склонений (1 год, 2 года, 5 лет).
   - Проверка API и работы с Базой Данных (БД).
3. **Регрессионное тестирование**
   - Прогон всех Smoke-тестов и ключевых проверок математики перед каждым релизом (пушем в `main`), чтобы убедиться, что новые механики (например, мультиплеер) не сломали одиночную игру.

## 2. Распределение: Автоматизация vs Ручное тестирование

Мы не пытаемся автоматизировать всё подряд. Наш девиз: **"Роботу — цифры, человеку — чувства"**. (неплохо так нейронка придумала)

| Зона ответственности | Что проверяем | Инструменты |
| :--- | :--- | :--- |
| 🤖 **Автотесты** | Жесткая логика, переходы состояний, математика, блокировки команд (например, `work` до 16 лет), работа с API и БД. | Playwright (E2E), Postman (API), SQL (БД). |
| 👁️ **Ручное тестирование** | Визуал (мерцание ASCII-арта, верстка, цвета), UX (удобство ввода, скорость печати ИИ КЗ), анимации, "ощущения" от игры. | Глаза, браузер, DevTools. |

## 3. Инструментарий

- **E2E-тесты (UI):** Playwright (JavaScript).
- **Тестирование API:** Postman / Insomnia.
- **Работа с БД:** DBeaver / SQLite Studio.
- **Ручные чек-листы, тест-кейсы:** Markdown-файлы в репозитории.

## 4. Definition of Done (Критерии готовности задачи)

Задача считается выполненной, если:
1. Код написан и работает.
2. Пройдены соответствующие Smoke-тесты.
3. Проверены граничные случаи (если применимо).
4. Визуал проверен вручную.
5. Тест-кейсы обновлены в репозитории.
