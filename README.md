# IlluzShow-Game

Игра по мотивам веб-сериала **ИллюзШоу** (автор — [PollMixan](https://www.youtube.com/@PollMixan)).

> Минимальный пет-проект, который будет развиваться по мере сил и вдохновения.

## Описание

**IllusionShow CLI Engine** — консольная игра, в которой вы управляете Сознанием (или Инженером Корабля Земля), проходящим партии в реалистичных иллюзорностях. Каждая партия — это жизнь в конкретной стране, городе и по конкретному адресу. После смерти наступает Чистилище, оценка КЗ и перерождение.

## Запуск

```
python main.py
```

При первом запуске начинается регистрация. При наличии сохранения (illusion_show_save.json) предлагается продолжить, начать новую игру или удалить сохранение.

## Регистрация

Игрок — чистое Сознание без тела на круглой платформе с подсветкой границ. Перед ним — ИИ Корабля Земля (сгусток светло-зелёных частиц).

ИИ приветствует, объясняет правила и назначает ID:

Тип	Формат ID	Примечание	
Обычное сознание - Сознание#NNNN	NNNN — случайное число 1–9999	
Инженер-Сознание - Сознание#NNNN_И#XXX,	XXX — случайное число 1–500	

Шанс стать инженером — 1%

Затем ИИ назначает партию (4995–5005), сценарий (семья, год, страна) и синхронизированную локацию (страна → город → адрес). Перед погружением — обратный отсчёт 5→1.

### explore

15 событий с 2–4 вариантами действия. Эффекты влияют на статы. 30% шанс найти предмет: Осколок Памяти, Кристалл Иллюзии, Пепел Мира, Эхо Голоса, Нить Судьбы. Возраст +1.

### work

Рандомные приросты: Интеллект 0–3, Мораль −1–2, Эмоции −2–1. Возраст +1.

### sleep

Случайный сон (6 вариантов). Если в инвентаре «Осколок Памяти» — Осознанность +2. Эмоции восстанавливаются до 20 (макс). Возраст +1.

## Смерть и Чистилище

При смерти:
- `alive = False`, `death_count + 1`, `in_purgatory = True`
- Автоматический переход в Чистилище

КЗ анализирует жизнь по формуле:

```
score = Интеллект + Мораль×2 + Осознанность×3 − Нарушения×2
```

Вердикт	Условие	Эффект при перерождении	
Возвышение	score ≥ 80	Осознанность +5	
Перерождение	40 ≤ score < 80	Без изменений	
Падение	score < 40	Нарушения +3	

## Перерождение

- "rebirth_count + 1"
- Возвращение на платформу Корабля Земля
- Назначается новая иллюзорность (4995–5005), новый сценарий, синхронизированная локация
- Обратный отсчёт 5→1
- Создание нового Аватар.

## Характеристики

| Стат | Диапазон | Как растёт | Особенности |
|------|----------|------------|-------------|
| Интеллект | 0–∞ | explore, work | Влияет на оценку КЗ |
| Мораль | 0–∞ | explore (выборы) | Влияет на оценку КЗ |
| Эмоции | 0–20 | sleep (+2), события | Кап на 20 |
| Осознанность | 0–∞ | explore, sleep (с Осколком), Возвышение | **Сохраняется между жизнями** |
| Нарушения | 0–∞ | некоторые события, Падение | **Сохраняются между жизнями** |

## 11. Чистилище (purgatory)

- Белая пустота
- КЗ анализирует жизнь
- Формула оценки:

```

score = Интеллект + Мораль×2 + Осознанность×3 - Нарушения×2

```

- Вердикты:
  - **score ≥ 80**: Возвышение
  - **40 ≤ score < 80**: Перерождение
  - **score < 40**: Падение
- Автоматический переход к Перерождению

## 12. Перерождение (rebirth)

- rebirth_count + 1
- Возвращение на платформу Корабля Земля
- ИИ приветствует
- Бонусы/штрафы от вердикта:
  - Возвышение: Осознанность +5
  - Падение: Нарушения +3
  - Перерождение: без изменений
- ИИ назначает новую иллюзорность (пока что рандом в пределах 4995–5005, новый сценарий, синхронизированная страна→город→адрес)
- Обратный отсчёт 5→1
- Падение, создание нового Аватара
