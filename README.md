# WEB-IlluzShow-Game

**ИЛЛЮЗGAME** — фанатская текстовая игра по мотивам вселенной [«ИллюзШоу»](https://www.youtube.com/@PollmixaN), автор вселенной — **PollmixaN**.

## О проекте

Это самостоятельная фанатская игровая реализация: оригинальный мир принадлежит его авторам. Автор проекта — фанат «ИллюзШоу» и ковчеговец. Это также пет-проект, который развивается по мере сил, времени и вдохновения и будет служить как портфолио в будущем.

Разработка началась **19.08.2026**, первая веб-версия вышла **10.09.2026**. В реализации кода участвовали такие нейросети, как: Kimi, Claude, ChatGPT, DeepSeek и Qwen на бесплатных тарифах. Творческое направление задаёт автор, ИИ помогает воплотить его в коде.

- Связь с автором: Telegram - [@slava_kos_2006](https://t.me/slava_kos_2006).
- Текущая реализация — браузерная. Прежняя Python-версия в архиве archived python version больше не поддерживается: я заменил её на веб ради простого запуска.

## Игровой цикл

```text
Регистрация Сознания
        ↓
Назначение партии
        ↓
Рождение аватара
        ↓
Жизнь: исследование → выборы / работа / сон
        ↓
Смерть
        ↓
Чистилище → анализ результатов ИИ Корабля Земля
        ├─ следующая партия → новый аватар
        └─ запрос на выход → сюжетная кат-сцена
```

По сюжету память аватара о прошлой партии стирается, что скоро будет добавлено в игру. При этом Сознание сохраняет следы опыта: осознанность, нарушения, баланс Мрака и Света, счётчики и сведения о посещённых местах продолжаются между партиями. Интеллект и эмоции нового аватара назначаются заново и меняются со временем. Мораль зависит от соотношения Мрака и Света, чем больше того или другого, тем больше или меньше значение морали.

## Регистрация Сознания

- Обычный идентификатор: `Сознание#N`, где `N` — случайное число от **1 до 9999**, без обязательного дополнения нулями.
- С вероятностью **1%** Сознание регистрируется инженером: `Сознание#N_ИM`, где `M` — от **1 до 500**. Обычное Сознание получает оставшиеся **99%**.
- Начальный Мрак — случайное целое значение **40–60%**, Свет равен `100 − Мрак`.
- Выбранный визуальный стиль записывается в состояние игры.

Статус инженера — часть регистрации и профиля; отдельного набора инженерных команд текущая версия пока не предоставляет.

## Назначение партии

Каждый раз выбираются стартовый сценарий, семья, город, адрес и тип местности. В семье используются две разные профессии: первая из сценария, вторая — случайная из остальных.

Не путайте два показателя:

- **Иллюзорность в назначении и профиле** (`party_number`) каждый раз случайно выбирается в диапазоне **4995–5005**.
- **Внутренний уровень иллюзорности** (`illusion_level`) начинается с **5000** и меняется по вектору партии. 

При преобладании Света вектор называется **«Возвышение»**, Мрака — **«Падение»**, при равенстве — **«Нейтральный»**. Названия и реплики ИИ не гарантируют конкретную сложность событий. 
Порядковый номер партии равен числу перерождений плюс один. Обычный отсчёт перед погружением — **5 секунд**, при автоматическом назначении по таймеру Чистилища — **10 секунд**.

## Рождение аватара и возраст

Новый аватар получает номер `#1`, `#2` и далее, начинает с возраста **0**. Интеллект и эмоции независимо выбираются в диапазоне **5–15**. Нарушения переходят из предыдущего состояния. Начальные характеристики запоминаются для итогового сравнения в Чистилище.

`explore`, `work` и `sleep` увеличивают возраст по текущему этапу, а не всегда на единицу. Справочные команды возраст не меняют.

| Этап | Возраст | Шаг за действие |
|---|---|---:|
| Раннее детство | 0–3 | 0,5 |
| Дошкольный возраст | 3–5 | 0,5 |
| Детство | 5–10 | 1 |
| Предподростковый | 10–15 | 1 |
| Подростковый | 15–20 | 1 |
| Молодость | 20–25 | 1 |
| Ранняя зрелость | 25–30 | 1 |
| Зрелость | 30–40 | 1 |
| Средняя зрелость | 40–50 | 1 |
| Поздняя зрелость | 50–60 | 1 |
| Пожилой возраст | 60–70 | 1 |
| Старость | 70–76,5 | 0,5 |

Нижняя граница включена, верхняя относится к следующему этапу. При достижении **76,5** жизнь завершается и начинается Чистилище.

## Команды

Команды вводятся латиницей и подтверждаются Enter. Регистр не важен; принимаются **однозначные префиксы**. Например, `exp` означает `explore`, но `s` неоднозначно между `stats`, `sleep` и `save`.

Командная строка работает в основной игровой сцене. Во время выполнения действия, выбора, кат-сцены или специального запроса ввод управляется соответствующей сценой: обычные команды в эти моменты не доступны.

| Команда | Действие |
|---|---|
| `help` | Справка по командам |
| `profile` | ID Сознания, аватар, партия, иллюзорность, семья, локация и счётчики |
| `stats` | Характеристики и вектор партии |
| `explore` | Возрастное событие с выбором |
| `work` | Работа с изменением характеристик |
| `sleep` | Сон и случайное сновидение |
| `inventory` | Просмотр инвентаря |
| `achieves` | Просмотр открытых достижений |
| `die` | Досрочное завершение жизни с подтверждением |
| `save` | Запись состояния в браузер |
| `info` | Внутриигровая заметка об игре и авторе |

**`travel` пока не реализована как команда текущей веб-версии.** Локация меняется при назначении следующей партии. Для достижений используется именно `achieve`, перерождение проходит через Чистилище, а сюжетный выход — через запрос ИИ.

### Исследование — `explore`

В игре **24 возрастных события** — по два для каждого из 12 этапов. Каждое предлагает три варианта поведения: они меняют характеристики и иногда число нарушений. Возраст и название этапа выводятся перед событием.

В последние **25%** этапа могут появляться события следующего: вероятность их выбора постепенно растёт от 0% к 70% у верхней границы. После выбора меняются баланс Мрака и Света, возраст и история действий; проверяются достижения.

### Перемещение — `travel`

В старой Python-истории команда упоминалась, но в актуальном обработчике веб-версии её нет. В пределах текущей жизни отдельного интерактивного перемещения между городами или адресами не предусмотрено.

### Работа — `work`

За одно действие случайно меняются:

- интеллект: **0…+3**;
- мораль: **−1…+2**;
- эмоции: **−2…0**.

Возраст увеличивается по этапу, действие добавляется в историю. Моральный результат работы влияет на баланс. Нижняя граница характеристик при применении эффектов — **0**.

### Сон — `sleep`

Показывается одно из **четырёх сновидений**. Эмоции пересчитываются как `min(15, эмоции + 1)`: при обычных значениях это прибавка до 15, но значение выше 15 будет снижено до 15. Возраст увеличивается по текущему этапу.

Сон **не прибавляет осознанность** в характеристиках и не выдаёт предмет или «осколок». Если действие не завершилось возрастной смертью, оно сдвигает баланс на **1 пункт в сторону Света**.

## Характеристики и баланс Мрака/Света

| Параметр | Что происходит в игре |
|---|---|
| Интеллект | Меняется в событиях и работе; назначается заново при рождении |
| Мораль | Меняется в событиях и работе; влияет на баланс; назначается заново |
| Эмоции | Меняются в событиях, работе и сне; назначаются заново |
| Осознанность | Меняется в событиях и переносится между партиями |
| Нарушения | Накапливаются за некоторые выборы и переносятся между партиями |

Шкалы характеристик в `stats` имеют **10 делений по 5 очков**. Числовое значение показывается отдельно: заполненная шкала не означает жёсткий предел 50.

Мрак и Свет находятся в диапазоне **0–100%**, их сумма — **100%**. Для событий и работы сдвиг вычисляется по эффектам:

```text
Сдвиг к Свету = 2 × изменение морали
               − 3 × изменение нарушений
               + изменение осознанности
```

Положительный результат усиливает Свет, отрицательный — Мрак. В Чистилище дополнительно учитывается сумма изменений интеллекта, морали и эмоций относительно начала партии.

**Полные 100% Света или Мрака сами по себе не запускают смерть или перерождение.** После исследования игра может вывести сообщение о критическом пределе, но автоматический переход по этому условию не реализован.

## Смерть, Чистилище и перерождение

Жизнь заканчивается при достижении **76,5** или после подтверждения `die`. Увеличивается счётчик смертей, проверяются достижения, затем Сознание возвращается на платформу Чистилища.

ИИ Корабля Земля показывает изменения интеллекта, морали и эмоций за партию, выводит баланс и корректирует его по результатам. После анализа увеличивается счётчик перерождений и открывается режим запроса перед следующей партией.

- Кнопка **«Продолжить игру»** ведёт к новому назначению.
- Таймер начинается с **3:20**. Когда остаётся **20 секунд**, срабатывает автоматическое назначение; последующее погружение отсчитывается с 10.
- Три подряд ввода, распознанных как бессвязные, также приводят к автоматическому назначению.
- Для сюжетного выхода можно написать, например, **«Хочу выйти из иллюзорности»**, затем подтвердить кнопкой **«Да»** или фразой **«Да, хочу выйти»**.

Запрос на выход запускает отдельную визуальную кат-сцену с прощанием ИИ и финальным экраном. Это **сюжетный выход**, а не закрытие вкладки браузера; он сохранён после удаления консольных `quit`/`exit`/`q`. На пути к финалу игра пытается сохранить состояние.

При следующем рождении сохраняются ID и статус Сознания, осознанность, нарушения, баланс, внутренний уровень и выбранная гамма, счётчики смертей/перерождений, посещённые места, инвентарь и история действий. Аватар, возраст, стартовые интеллект/мораль/эмоции и параметры новой партии назначаются заново. В текущем игровом цикле наполнение инвентаря не предусмотрено.

## Скрытые достижения

В текущем HTML определено **5 достижений**. Если хотите открыть их самостоятельно, не раскрывайте список.

| Достижение | Условие |
|---|---|
| Первая смерть | Хотя бы одна смерть |
| Пробуждённый | Осознанность не ниже 50 |
| Нарушитель | Не меньше 10 нарушений |
| Нравственный идеал | Мораль не ниже 30 |
| Вечный странник | Счётчик перерождений не меньше 5 |

Проверка выполняется после исследования и при смерти, а не после каждой команды. Поэтому уведомление может появиться позднее достижения порога; в частности, счётчик перерождений увеличивается уже после проверки при смерти. `achieve` показывает только уже открытые достижения.

**Флаги достижений не входят в сохранение.** Они сохраняются между партиями в рамках открытой страницы, но сбрасываются после её перезагрузки. Достижения, условия которых ещё выполнены, могут открыться повторно при следующей проверке.

## Сохранение

Команда **`save`** записывает состояние игры в `localStorage` под ключом **`illusionShowSave`**. Отдельный JSON-файл на диске не создаётся. Записываются характеристики, возраст, данные текущей партии и Сознания, баланс, счётчики, история, инвентарь, выбранная гамма и списки посещённых мест. Сериализация использует JSON, но хранилище остаётся браузерным.

После заставки, если запись найдена, предлагаются **«Продолжить»**, **«Новая игра»** и **«Удалить сохранение»**. Два последних варианта удаляют прежнюю запись и начинают новую регистрацию.

> **Важное ограничение:** «Продолжить» не восстанавливает жизнь точно с точки сохранения. Загрузка вызывает рождение аватара: возраст становится 0, интеллект/мораль/эмоции и начальные показатели пересоздаются, аватар считается живым. Сохранённые осознанность, нарушения, баланс, счётчики и накопленные данные остаются. Сцена Чистилища или сюжетного финала не возобновляется.

Сохранение привязано к браузеру, профилю и origin страницы, не синхронизируется с GitHub и не переносится автоматически на другое устройство. Удаление данных сайта может уничтожить запись. Для `file://` правила хранения зависят от браузера; не рассчитывайте на гарантированную доступность записи после перемещения или переименования HTML. Недоступное хранилище или повреждённая запись могут помешать сохранению либо загрузке.

Не полагайтесь на постоянное автосохранение: обычные действия сами запись не обновляют. Кроме ручной команды, попытка сохранения есть в кат-сцене выхода, но её успешность не гарантирована.

## Цветовая схема

Интерфейс использует **CSS и HTML**, а не ANSI-коды терминала.

| Элемент | Цвет в текущем интерфейсе |
|---|---|
| Основной фон | Тёмный сине-фиолетовый `#272866` |
| Основной текст | Светло-серый `#e0e0e0` |
| Заголовки сцен, подписи, рамки выбора | Мятный `#63e6be` |
| Кубики верхнего заголовка | Голубой `#4cd8e2` |
| Обычные реплики ИИ | Лаймовый `#94d82d` |
| Реплики ИИ в финальной части выхода | Светло-синий `#a5d8ff` |
| Интеллект / мораль / эмоции в `stats` | Голубой `#74c0fc` / зелёный `#51cf66` / жёлтый `#fcc419` |
| Осознанность / нарушения в `stats` | Пурпурный `#cc5de8` / красный `#ff6b6b` |

При регистрации можно выбрать **классический баланс** — Мрак `#cc5de8`, Свет `#51cf66` — или **монохромный** — чёрный `#000000` и белый `#ffffff`. Этот выбор не меняет весь интерфейс: итоговая сводка Чистилища использует собственные цвета Мрака `#a610c7` и Света `#fcc419` независимо от выбранной гаммы.

Заставка и сюжетный выход содержат мерцание и матричные визуальные эффекты.

## Архитектура

Текущая игра размещена в одном **`ИЛЛЮЗGAME.html`**:

- HTML задаёт слои вывода, ввод, заставку и экраны кат-сцен;
- встроенный CSS оформляет интерфейс и адаптивные элементы;
- встроенный JavaScript содержит сценарии, возрастные события, состояние игры, команды и переходы между сценами;
- `localStorage` хранит сериализованное игровое состояние;
- Canvas используется для визуального шума заставки и финала.

Python-модули, терминальные ANSI-схемы и файловые JSON-сохранения относятся к прежней версии, а не к текущему запуску. Здесь описан актуальный HTML; структура каталогов и ветка репозитория не предполагаются.

## Известные ограничения

- Текст `info` содержит историческую заметку на 19.09.2026, а не актуальную сводку версии.
- Загрузка сохранения пересоздаёт аватар; достижения не сохраняются между перезагрузками страницы. Подробности приведены выше.
- Таймер Чистилища останавливается при запросе на выход и после отклонённого подтверждения не запускается заново.
- В финальной анимации остаётся ошибка обращения к функции остановки шума до её инициализации; финал не следует считать полностью исправленным.

README описывает правила по исходному HTML, без заявления о проверке запуском. Известные ограничения здесь не означают, что код был исправлен.
