## Основа проекта

Оригинальный мир и исходный веб-сериал принадлежат их авторам. Этот репозиторий представляет собой самостоятельную фанатскую реализацию игровой концепции и CLI-механик.

## О проекте

**IllusionShow CLI Game** — текстовая игра, в которой игрок выступает в роли **Сознания**, погружающегося в различные иллюзорности Корабля Земля.

Сознание получает случайную партию, в которой ему назначаются семья, год, страна, город и конкретный адрес. Внутри партии игрок проживает жизнь через исследование мира, случайные события, моральные решения, работу и сон. (Пока всё очень упрощенно)

После смерти аватара начинается **Чистилище**: КЗ анализирует результаты прожитой жизни, формирует дальнейший вектор и запускает следующее перерождение.

Главная особенность текущей версии — постепенное накопление опыта между жизнями. Память аватара стирается, но само Сознание сохраняет ключевые характеристики и результаты предыдущих партий.

## Как это выглядит?

Погружение в мир иллюзорностей → пребывание в партии → жизнь Аватара через события и действия → смерть → Чистилище → оценка КЗ → перерождение.

```text
Регистрация
   ↓
Назначение партии
   ↓
Рождение Аватара
   ↓
Жизнь в иллюзорности
   ↓
Смерть
   ↓
Чистилище
   ↓
Вердикт КЗ
   ↓
Перерождение
   ↺
```

## Архитектура

```text
IlluzShow-Game/
├── main.py       # точка входа и главный игровой цикл
├── config.py     # версия, сохранение, ANSI-цвета и цветовые схемы
├── data.py       # страны, города, адреса, сценарии, события и достижения
├── state.py      # GameState и работа с сохранением
├── scenes.py     # регистрация, партии, события, смерть, Чистилище и перерождение
└── utils.py      # вывод, ввод, перенос текста и вспомогательные функции
```

### Принцип разделения ответственности

Основная игровая логика разделена по ответственности:

- `main.py` отвечает за игровой цикл и маршрутизацию команд;
- `state.py` хранит состояние Сознания и операции сохранения;
- `scenes.py` содержит игровые сцены и механику;
- `data.py` содержит данные контента;
- `utils.py` содержит терминальные утилиты;
- `config.py` хранит глобальные настройки интерфейса.

Такое разделение позволяет расширять контент отдельно от ядра игры.

## Запуск

Проект не использует внешние Python-зависимости и рассчитан на запуск из терминала.

### Требования

- Python 3.x
- терминал с поддержкой ANSI-цветов

### Запуск

```bash
git clone https://github.com/Developer151/IlluzShow-Game.git
cd IlluzShow-Game
python main.py
```

В Linux/macOS при необходимости:

```bash
python3 main.py
```

## Регистрация Сознания

В начале игры Сознание проходит регистрацию в базе Корабля Земля.

Существует два варианта идентификатора:

```text
Сознание#NNNN
Сознание#NNNN_И#XXX
```

Обычное Сознание получает случайный номер от `1` до `9999`.

С шансом **1%** игрок становится Инженером и получает дополнительный идентификатор Инженера от `1` до `500`.

После регистрации игроку показывается текущее соотношение Мрака и Света.

### Назначение партии

Корабль Земля автоматически выбирает:

- номер иллюзорности: `4995–5005`;
- семью и вторую профессию;
- год;
- страну;
- город;
- конкретный адрес;
- тип местности.

Профессия берётся из набора сценариев, а вторая профессия случайно подбирается из общего списка.

Пример:

```text
Семья врача и моряка, 2003, Россия
Москва, городская местность
ул. Ленина, д. 22, кв. 15
```

## Локации

Локации хранятся в структуре:

```text
Страна
└── Город
    └── Список адресов
```

Сейчас в проекте:

**20 стран · 35 городов · 100+ адресов**

При назначении партии город и адрес всегда выбираются из той же страны, которая указана в сценарии.

## Рождение Аватара

В каждой новой партии - новый аватар:

```text
Аватар #1
Аватар #2
Аватар #3
...
```

При рождении заново генерируются:

- Интеллект: `5–15`;
- Мораль: `5–15`;
- Эмоции: `5–15`.

При этом между жизнями сохраняются:

- Осознанность;
- Нарушения;
- Достижения;
- общий прогресс Сознания;
- история;
- собранные предметы;
- посещённые локации.

Возраст увеличивается на один цикл при выполнении соответствующих действий.

## Команды

| Команда | Назначение | Доступность |
|---|---|---|
| `help` | показать справку | всегда |
| `profile` | профиль Сознания и Аватара | всегда |
| `stats` | характеристики | всегда |
| `explore` | исследовать мир и получить событие | только живой |
| `travel` | путешествие | только живой, **в разработке** |
| `work` | работа | только живой |
| `sleep` | сон | только живой |
| `inventory` | показать инвентарь | всегда |
| `achievements` | показать достижения | всегда |
| `die` | закончить текущую жизнь | только живой |
| `save` | сохранить игру | всегда |
| `quit` | сохранить и выйти | всегда |
| `exit` | аналог `quit` | всегда |
| `q` | сокращённый выход | всегда |

Команды поддерживают ввод по префиксу. Например, ввода `inv` достаточно для вызова `inventory`.

## Жизнь в иллюзорности

### `explore`

Исследование запускает случайное событие с 2–4 вариантами действий. Выбор изменяет характеристики Сознания.

Есть **30% шанс** найти предмет:

```text
Осколок Памяти
Кристалл Иллюзии
Пепел Мира
Эхо Голоса
Нить Судьбы
```

После события возраст увеличивается на `1`, запись добавляется в историю, а система проверяет достижения.

### `travel`

Команда присутствует в интерфейсе, но полноценная система путешествий пока **в разработке**.

### `work`

Случайные изменения:

```text
Интеллект: 0–3
Мораль:   -1–2
Эмоции:   -2–1
```

Возраст `+1`.

### `sleep`

Случайное сновидение. Если есть **Осколок Памяти**, Осознанность `+2`. Эмоции восстанавливаются до максимума `20`. Возраст `+1`.

## Смерть и Чистилище

Команда `die` завершает текущую жизнь.

После смерти:

```text
alive = False
death_count += 1
in_purgatory = True
```

Игрок автоматически попадает в Чистилище.

КЗ анализирует результат предыдущей жизни, меняет баланс Мрака и Света и определяет направление следующей партии.

Возможные результаты:

```text
Возвышение
Падение
Нейтральный
```

После вынесения Вердикта КЗ запускается перерождение и автоматически назначается новая партия.

## Перерождение

При перерождении:

1. увеличивается счётчик перерождений;
2. назначается новая иллюзорность `4995–5005`;
3. выбирается новый сценарий;
4. подбираются новые город и адрес;
5. создаётся новый Аватар;
6. перед погружением запускается обратный отсчёт `5 → 1`.

Физический Аватар меняется, но ключевые параметры Сознания продолжают существовать между жизнями.

## Характеристики

| Характеристика | Назначение |
|---|---|
| **Интеллект** | влияет на развитие Сознания и оценку КЗ |
| **Мораль** | формируется поступками игрока и влияет на результат жизни |
| **Эмоции** | отражают эмоциональное состояние Аватара |
| **Осознанность** | ключевая характеристика, сохраняющаяся между жизнями |
| **Нарушения** | фиксируют негативные поступки и также сохраняются между жизнями |

Интеллект, Мораль и Осознанность могут расти без жёсткого верхнего лимита.

Эмоции ограничены значением `20`.

## Мрак и Свет

В начале новой игры генерируется баланс:

```text
Мрак: 40–60%
Свет: 60–40%
```

Сумма всегда равна 100%.

Преобладающая сила определяет вектор следующей партии:

| Баланс | Вектор |
|---|---|
| Свет > Мрак | Возвышение |
| Мрак > Свет | Падение |
| Мрак = Свет | Нейтральный |

Вектор влияет на изменение уровня иллюзорности перед следующей партией.

## Скрытые достижения

В проекте есть 6 скрытых достижений:

| Достижение | Условие |
|---|---|
| **Первое Упадение** | умереть впервые |
| **Пробудившийся** | достичь 50 Осознанности |
| **Искажённый** | набрать 10 Нарушений |
| **Светлый** | получить Мораль выше 30 |
| **Вечный** | переродиться 5 раз |
| **Гражданин Мира** | посетить все 20 стран |

Достижения сохраняются в состоянии игры.

## Сохранение

Состояние игры хранится в JSON-файле:

```text
illusion_show_save.json
```

Сохранение выполняется:

- вручную через `save`;
- автоматически при `quit` / `exit` / `q`.

При запуске существующее сохранение предлагается:

- продолжить;
- заменить новой игрой;
- удалить.

Состояние сериализуется через `GameState.to_dict()`.

## Цветовая схема

Проект использует ANSI-цвета и работает непосредственно в терминале.

Основная схема:

```text
Мрак → фиолетовый
Свет → зелёный
ИИ Корабля Земля → лаймовый
Положительные изменения → зелёный
Отрицательные изменения → красный
Предупреждения → жёлтый
Описания → серый
Сновидения → пурпурный
```

При старте новой игры можно выбрать:

1. **Классическую** — фиолетовый / зелёный;
2. **Монохромную** — чёрный / белый.

Для монохромного режима нужен не-черный фон терминала.

## Известные ограничения

На данный момент в проекте отсутствуют:

- полноценная система путешествий;
- мультиплеер;
- фракции;
- экономика;
- крафт;
- модификации;
- NPC с самостоятельным ИИ;
- полноценная привязка каждого события к конкретной локации;
- система времени суток;
- погода;
- возрастные стадии;
- социальные слои.

`travel` уже предусмотрен в интерфейсе, но его игровая логика пока не реализована.
