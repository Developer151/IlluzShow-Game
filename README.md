# IllusionShow CLI Engine v0.2.1 — Тестовая документация

## 1. Общее описание

CLI-игра по мотивам ИллюзШоу. Игрок управляет Сознанием (Инженером Корабля Земля), которое проходит партии в реалистичных иллюзорностях. Каждая партия — это жизнь в конкретной стране, городе, адресе. После смерти — Чистилище, оценка КЗ, перерождение.

---

## 2. Архитектура проекта

``` 
illusion_show/
├── main.py      — точка входа, главный цикл, вызов всех сцен
├── config.py    — константы, ANSI-цвета
├── utils.py     — утилиты: печать, ввод, разделители
├── data.py      — данные: страны, города, адреса, сценарии, события, достижения
├── state.py     — GameState, сохранение/загрузка/удаление
└── scenes.py    — все игровые сцены

```

## 3. Запуск и меню

### 3.1 Первый запуск
- Выводится логотип "ILLUSION SHOW CLI ENGINE 0.2.1"
- Начинается registration_scene

### 3.2 Повторный запуск (есть save.json)
- Показывается ID Сознания
- Меню:
  1. **Продолжить** — загрузка
  2. **Новая игра** — удаление save, новая регистрация
  3. **Удалить сохранение** — удаление save, новая регистрация

## 4. Регистрация (registration_scene)

### 4.1 Описание сцены
- Игрок — чистое Сознание без тела
- Круглая платформа с подсветкой границ
- Внизу — фиолетовое свечение и космос
- Перед игроком — сгусток светло-зелёных частиц (ИИ Корабля Земля)

### 4.2 Диалог ИИ (всё печатается посимвольно)
1. «Приветствую, сознание.»
2. «Скоро начнётся ваша первая партия в одной из иллюзорностей Корабля Земля.»
3. «Местом проведения первых партий для сознаний являются иллюзорности в пределах 4995–5005-й.»
4. «Мы автоматически выберем для вас иллюзорность в этом диапазоне.»
5. «Перед каждой новой партией у вас будет стираться память.»
6. «Но Сознание остаётся. Оно накапливает опыт, даже если не помнит.»
7. «Каждое перерождение — новая маска. Но маска носит следы.»

### 4.3 Присвоение ID
- ИИ назначает ID в формате "Сознание#NNNN" для обычных сознаний
- Для сознаний-инженеров назначает ID в том же формате, какой у обычных сознаний, но с пропиской "И#XXX", где XXX — случайное число 1–500
- Пример: "Сознание#4995", "Сознание #4032_И#19"
- Сообщение (для обычных сознаний): "Вам присвоен идентификатор: Сознание#4995. Вы — простое сознание с характеристиками как у всех остальных."
- Сообщение (для инженеров): "Вам присвоен идентификатор: Сознание#4032_И#19. Вы - инженер, состоите в Персонале Корабля Земля". 

### 4.4 Назначение партии (party_assignment)
- ИИ анализирует иллюзорности (имитация загрузки, 0.8 сек)
- Рандомно выбирается:
  - **Номер партии**: 4995–5005 (временное ограничение, потом 1-10000 будет)
  - **Сценарий**: (семья, год, страна)
  - **Город и адрес**: из той же страны
- ИИ объявляет выбор
- Обратный отсчёт 5→1 секунда (красные цифры)
- Падение, пробуждение

## 7. Рождение Аватара (create_avatar)

- Создаётся "Аватар #N" (N = rebirth_count + 1)
- Город и адрес назначаются из страны сценария
- Сброс статов (кроме Осознанности и Нарушений):
  - Интеллект: 5–15 (рандом)
  - Мораль: 5–15 (рандом)
  - Эмоции: 5–15 (рандом)
  - Осознанность: сохраняется от прошлых жизней
  - Нарушения: сохраняются от прошлых жизней
- Сообщение: «Память о регистрации стёрта. Остаётся только ощущение — ты здесь не впервые.»

## 9. Команды

### 9.1 help
- Выводит список всех команд с описанием

### 9.2 profile
- Показывает полный профиль:
  - ID Сознания
  - Аватар
  - Партия #N
  - Стартовый сценарий (семья, год, страна)
  - Текущая страна, город, адрес
  - Возраст в циклах
  - Перерождения, смерти
  - Все 5 статов
  - Прогресс достижений

### 9.3 stats
- Статистика в виде ASCII-шкал (5 делений):
```

Интеллект:   ████████░░░░░░░░░░░░ 8
Мораль:      ██████████░░░░░░░░░░ 10
Эмоции:      ██████░░░░░░░░░░░░░░ 6
Осознанность:████░░░░░░░░░░░░░░░░ 4
Нарушения:   ██░░░░░░░░░░░░░░░░░░ 2

```

### 9.4 explore (только живой)
- Случайное событие из EVENTS_POOL
- 15 событий:
  1. Встреча с соседом
  2. Моральный Выбор (с выбором)
  3. Провал Памяти
  4. Иллюзия Успеха
  5. Тишина
  6. Внутренний Голос
  7. Ритуал (с выбором)
  8. Потеря
  9. Пробуждение
  10. Работа
  11. Дождь
  12. Полицейский участок
  13. Ночной автобус
  14. Супермаркет
  15. Соседский скандал
- Эффекты: +/- к статам
- 30% шанс найти предмет: Осколок Памяти, Кристалл Иллюзии, Пепел Мира, Эхо Голоса, Нить Судьбы
- Возраст +1
- Проверка достижений

### 9.5 travel (только живой, пока не работает)
- Выбор локации:
  - Адреса в текущем городе
  - Другие города этой страны (→ Город)
  - Другие страны (→→ Страна)
- При смене страны: рандомный город и адрес из новой страны
- Возраст +1

### 9.6 work (только живой)
- Рандомные приросты:
  - Интеллект: 0–3
  - Мораль: -1–2
  - Эмоции: -2–1
- Возраст +1

### 9.7 sleep (только живой)
- Случайный сон (6 вариантов)
- Если в инвентаре «Осколок Памяти» → Осознанность +2
- Эмоции восстанавливаются до 20 (max)
- Возраст +1

### 9.8 inventory
- Список предметов или «(пусто)»

### 9.9 achievements
- 6 скрытых достижений:
  1. **Первое Упадение** — умереть впервые
  2. **Пробудившийся** — Осознанность ≥ 50
  3. **Искажённый** — Нарушения ≥ 10
  4. **Светлый** — Мораль > 30
  5. **Вечный** — переродиться 5 раз
  6. **Гражданин Мира** — посетить все 20 стран
- Статус: [✓] разблокировано / [ ] заблокировано

### 9.10 die (только живой)
- Подтверждение: «Ты уверен? Это необратимо. (да/нет)»
- Если да → переход в сцену Смерть

### 9.11 rebirth (только в Чистилище)
- Переход к перерождению
- Если не в Чистилище → ошибка

### 9.12 save
- Ручное сохранение в illusion_show_save.json

### 9.13 quit / exit / q
- Автосохранение + выход

## 10. Смерть (die)

- Сообщения:
```
«Твоё воплощение угасает...»
«Плоть рассыпается. Мир исчезает.»
«Остаётся только Сознание.»
```

alive = False, death_count + 1, in_purgatory = True
- Проверка достижений
- Автоматический переход в Чистилище

## 11. Чистилище (purgatory)

- Белая пустота
- КЗ анализирует жизнь
- Формула оценки:

```

score = Интеллект + Мораль×2 + Осознанность×3 - Нарушения×2

```

- Вердикты:
  - **score ≥ 80**: Возвышение
  - **40 ≤ score < 80**: Перерождение
  - **score < 40**: Падение
- Автоматический переход к Перерождению

## 12. Перерождение (rebirth)

- rebirth_count + 1
- Возвращение на платформу Корабля Земля
- ИИ приветствует
- Бонусы/штрафы от вердикта:
  - Возвышение: Осознанность +5
  - Падение: Нарушения +3
  - Перерождение: без изменений
- ИИ назначает новую иллюзорность (пока что рандом в пределах 4995–5005, новый сценарий, синхронизированная страна→город→адрес)
- Обратный отсчёт 5→1
- Падение, создание нового Аватара

## 13. Сохранение

### 13.1 Формат
JSON-файл illusion_show_save.json со всеми полями GameState

### 13.2 Когда сохраняется
- Вручную: команда save
- При выходе: команда quit
- **Не автосохраняется** при смерти/перерождении (только вручную)

### 13.3 Загрузка
- При запуске проверяется наличие файла
- Если есть — меню: Продолжить / Новая игра / Удалить

## 14. Характеристики (статы)

| Стат | Диапазон | Как растёт | Особенности |
|------|----------|------------|-------------|
| Интеллект | 0–∞ | explore, work | Влияет на оценку КЗ |
| Мораль | 0–∞ | explore (выборы) | Влияет на оценку КЗ |
| Эмоции | 0–20 | sleep (+2), события | Кап на 20 |
| Осознанность | 0–∞ | explore, sleep (с Осколком), Возвышение | **Сохраняется между жизнями** |
| Нарушения | 0–∞ | некоторые события, Падение | **Сохраняются между жизнями** |

## 15. Тестовые сценарии

### ТС-01: Первая регистрация
1. Удалить save.json
2. Запустить main.py
3. Проверить: логотип → описание платформы → диалог ИИ → присвоение ID → назначение партии → отсчёт → пробуждение
4. Ожидаемый результат: ID формата И#XXX, партия 4995–5005, страна совпадает с городом

### ТС-02: Полный цикл жизнь→смерть→перерождение
1. explore 3 раза
2. die → подтвердить
3. Проверить Чистилище → КЗ → вердикт
4. rebirth
5. Проверить: новая партия, новая страна/город/адрес, синхронизация сохранена, Осознанность/Нарушения не сброшены

### ТС-03: Путешествие между странами
1. travel
2. Выбрать →→ Страна (другая)
3. Проверить: страна изменилась, город из новой страны, адрес из нового города

### ТС-04: Достижение «Гражданин Мира»
1. Многократно travel →→ в новые страны
2. Проверить achievements после посещения всех 20 стран

### ТС-05: Сохранение прогресса
1. Выполнить несколько команд
2. save
3. quit
4. Перезапустить → Продолжить
5. Проверить: все статы, инвентарь, посещённые локации сохранены

### ТС-06: Проверка стирания памяти
1. rebirth
2. Проверить profile: rebirth_count увеличился, avatar_name изменился
3. Проверить: scenario изменился, но consciousness_id тот же

### ТС-07: ИИ печатает посимвольно
1. Внимательно следить за регистрацией
2. Каждая фраза ИИ должна появляться побуквенно, а не мгновенно

### ТС-08: Обратный отсчёт
1. Перед погружением должны появляться цифры 5,4,3,2,1 с интервалом ~1 сек
2. Цифры красные и жирные

## 16. Известные ограничения v0.2

- Нет мультиплеера
- Нет фракций
- Нет экономики
- Нет крафта
- Нет модов
- Нет ИИ NPC (только ИИ Корабля Земля)
- События не привязаны к конкретным адресам/странам (общий пул)
- Нет системы времени суток
- Нет погоды
- Нет возрастных стадий (детство→старость)
- Нет социальных слоёв
